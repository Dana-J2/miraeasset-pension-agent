# 🛡️ 연금의 파수꾼
### HyperCLOVA X 기반 연금 AI Agent

> **더 벌게 해주는 존재가 아니라,  
> 모르는 사이에 잃는 것을 막아주는 존재**

제10회(2026) 미래에셋증권 AI Festival을 위해 개발한  
**연금 제도·세제·상품 통합 AI Agent**입니다.

사용자의 질문에 단순히 답하는 것을 넘어,  
답변 뒤에서 사용자가 미처 인지하지 못한 **혜택·행동 위험·비용 누수**를 한 번 더 점검하는  
**Guardian 기반 연금 Agent**를 제안합니다.

---

## 1. Problem

연금은 가입 이후에도 수령, 이전, 중도인출, 세금, 상품 운용 등  
수많은 의사결정을 반복해야 하는 장기 금융상품입니다.

하지만 사용자는 자신이 무엇을 놓치고 있는지 알지 못하기 때문에  
놓친 혜택이나 비용, 행동상 위험을 질문조차 하지 못할 수 있습니다.

> **사용자는 모르는 것을 질문할 수 없다.**

저희는 연금에서의 손실을 단순한 투자수익률 하락이 아니라 다음 세 가지로 정의했습니다.

| 손실 유형 | 예시 |
|---|---|
| 기회 손실 | 받을 수 있는 세제·제도상 혜택을 놓침 |
| 의사결정 손실 | 중도인출·실물이전 과정에서 불필요한 불이익 발생 |
| 비용 손실 | 같은 상품에서도 더 높은 비용의 판매클래스를 지속 이용 |

---

# 2. Solution — 연금의 파수꾼

일반적인 금융 Q&A Agent가 **사용자가 물어본 내용에 답하는 것**에 집중한다면,  
연금의 파수꾼은 Core 답변이 완성된 뒤 한 번 더 사용자의 상황을 점검합니다.

### 🟢 Opportunity Guard
**“더 받을 수 있는 건 없을까?”**

사용자가 놓치고 있는 세제·제도상 혜택을 점검합니다.

### 🟠 Action Guard
**“지금 이 행동을 해도 괜찮을까?”**

중도인출·실물이전 등 사용자가 하려는 행동에서  
추가로 확인해야 할 조건이나 불이익을 점검합니다.

### 🔵 Cost Guard
**“모르는 사이 새고 있는 돈은 없을까?”**

같은 펀드·같은 연금계좌 유형 안에서  
검증 가능한 더 낮은 비용의 판매클래스가 존재하는지 확인합니다.

> Guardian은 새로운 답변 생성기가 아닙니다.  
> **검증된 Core 답변 뒤에서 근거가 있는 포인트 하나만 추가로 확인하는 후단 안전 계층**입니다.
